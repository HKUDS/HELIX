# OpenCode Pi Hybrid Recipe

This recipe assembles the current OpenCode/Pi hybrid profile from source-traceable lego atoms.

Current capabilities:

- OpenCode foundation, session, hook, provider-plugin, tool registry, workspace, Web, and TUI surfaces.
- Pi Mono config, prompt, turn profile, cadence, acceptance, CLI, TUI, RPC, and Web UI surfaces.
- A 96-port binding split that keeps OpenCode and Pi source ownership explicit.
- Hybrid tool permission and extension loading policies that preserve both upstream personalities.
- Task-parity and live-provider-parity conformance hooks through the shared Helix runtime.

Use it as a concrete example of recomposing multiple recognized harnesses into one assembled agent runtime.
