# Hermes Agent Recipe

This recipe assembles the current Hermes Agent product profile from lego atoms and product shells.

Current capabilities:

- Hermes session, shell, and plugin personality atoms.
- Stable context prompt builder.
- Hermes shell hook permission policy and plugin manager loading.
- Python subprocess shell execution policy.
- SDK, CLI, TUI, API server, ACP, gateway, dashboard, and harness product shells.
- Fixture replay, upstream e2e parity, live provider parity, task parity, reverse assembly, and block-ledger conformance hooks.

Use it when you want to inspect how Hermes Agent is represented as a reusable Helix assembly.
