# claude-tap Notice

This directory contains Helix-owned integration files for the external
`claude-tap` tool: profile metadata, accepted artifact schemas, fixtures,
preflight helpers, and docs. It does not contain vendored `claude-tap` source
code.

- Upstream repository: https://github.com/liaohch3/claude-tap
- Python package: https://pypi.org/project/claude-tap/
- License: MIT
- Upstream license file: https://github.com/liaohch3/claude-tap/blob/main/LICENSE
- Copyright: Copyright (c) 2025 liaohch3

Users install `claude-tap` independently, for example with
`uv tool install claude-tap` or `pip install claude-tap`.
