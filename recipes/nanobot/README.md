# Nanobot Recipe

This recipe assembles the current Nanobot product profile from lego atoms and product shells.

Current capabilities:

- Nanobot-style session and plugin personality atoms.
- Nanobot session-history context builder.
- Nanobot tool policy and plugin loader wiring.
- Python subprocess shell execution policy.
- SDK, CLI, TUI, Web UI, server, and harness product shells.
- Fixture replay, upstream e2e parity, live provider parity, task parity, reverse assembly, and block-ledger conformance hooks.

Use it when you want to inspect how the Nanobot harness maps onto the shared Helix ports.
